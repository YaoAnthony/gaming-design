# Climb Proto — 「起跳即爆炸」房间制解谜原型

银河城 / Animal Well 式的房间制世界：**每一屏是一个独立小关卡**，`R` 只重置当前房间（像 Leap Year），
其他房间保持你改过的样子。角色可以平地跳，也能贴墙下滑时蹬墙跳（Celeste 式）。

核心机制：**每一次起跳都会在起跳点引发固定大小的爆炸**。地面起跳留坑，蹬墙跳削墙，
失去支撑的地形整块掉落——可以砸死怪物、堵住路线，也可以变成新的台阶或填平坑洞。
跳在哪里、什么时候跳，就是解谜本身。

Phaser 3 通过 CDN 引入，无需构建。

## 运行

```bash
cd climb-proto && python3 -m http.server 8081
```

- 游戏：http://localhost:8081
- 地图编辑器：http://localhost:8081/editor.html

## 地图编辑器

左边是物品栏（砖块 + 物件）和房间列表，右边是当前房间。左键画、右键擦、按住拖动连续画。

- 红框标出"一开始就会掉落"的地块（没有连到岩石），画的时候就能看到。
- 出生点全图唯一，画到新位置会自动清掉旧的。
- 「+ 加一排 / + 加一列」扩展世界；房间名会在进房间时显示，用来写谜题提示。
- 「从本房间试玩」把玩家放到当前房间的出生点（没有就放房间上方），ESC 回编辑器，R 重置房间。
- 改动自动存在浏览器 localStorage。「导出 / 导入 JSON」用来备份和交换；「复制为 world.js」贴进 `src/world.js` 后，正式游戏页面就用新地图。

## 砖块注册表（怎么加新砖块）

砖块和物件的能力全部在 `src/tiles.js` 里注册，地形、爆炸、掉落、贴图、编辑器物品栏都从注册表读，不认识具体字符。
模式是 **注册表（Registry）+ 能力特征组合（Trait / Strategy）**：

```js
defineTile({
  id: 'S', name: '沙土', desc: '像泥土，但爆炸范围外一圈也会被震碎',
  color: 0xd9a066,
  draw(g, x, y, T) { /* 用 Phaser Graphics 画在图集的 (x, y) 位置 */ },
}, Traits.Solid, Traits.Destructible(1));
```

可用的能力：

| 能力 | 含义 |
| --- | --- |
| `Traits.Solid` | 实心，挡住玩家、怪物、碎块 |
| `Traits.Anchor` | 锚点：自己永不掉落，相连的实心格子都被它撑住 |
| `Traits.Destructible(n)` | 可被爆炸摧毁；`n` 是额外感应半径（格），0 = 只在范围内碎，1 = 范围外一圈也碎 |
| `Traits.Chain` | 被波及后沿同类格子连锁崩塌 |
| `Traits.Hazard('提示')` | 碰到即死 |
| `Traits.Hidden` | 不在编辑器物品栏显示 |

物件用 `defineEntity({ id, name, texture, draw(g) => ({w, h}), spawn(scene, wx, wy, cell) })` 注册，
进游戏时由物件自己决定怎么生成（出生点记录位置、怪物加入巡逻组、终点画建筑）。

## 操作

| 按键 | 动作 |
| --- | --- |
| ← → / A D | 移动 |
| 空格 / ↑ / W | 起跳（起跳点爆炸） |
| 贴墙下滑时按跳 | 蹬墙跳（墙面爆炸） |
| R | 重置当前房间（地形、怪物、回到进入点） |

站在地上或贴墙时会显示爆炸预览：红色 = 会被炸掉的泥土，橙色 = 会崩塌的脆岩，白框 = 爆炸范围。

## 规则

- **泥土 `#`**：爆炸范围内的会被炸掉。
- **岩石 `R`**：炸不动，也是唯一的锚点。没有（经由相邻格子）连到岩石的地块会整块掉落。
- **脆岩 `B`**：比泥土多一格感应范围，被波及就整段连锁崩塌。用来做支柱、吊索。
- **沙土 `S`**：像泥土，但范围外一圈也会被震碎，不连锁。
- **尖刺 `X`**：碰到即死。掉下来的地块会把它盖住。
- **碎块**：整体垂直下落，落到实心格子上就并回地形。
  - 下落中的碎块压到玩家或怪物 → 死。落地时把人埋住 → 死。
  - 刚断裂、还没加速的碎块只会把玩家顶开（当天花板），给一点反应时间。
- 死亡 = 重置当前房间。地形在其他房间**不会**恢复。

## 房间

```
[E 填坑] [F 建筑]
[C 造路] [D 怪物]
[A 起点] [B 竖井]
```

| 房间 | 谜题 |
| --- | --- |
| A | 教学：站在泥土块顶上起跳，会向下炸穿掉进隧道 |
| B | 竖井里一根横梁封路，两端都连着井壁。蹬墙炸断任意一侧根部即可通过 |
| D | 站到柱顶起跳，脆岩断开，横梁砸进怪物走廊。怪物在横梁外面时会活下来 |
| C | 岩石台阶从地面够不到。在脆岩支柱**旁边**起跳震塌它，泥土块掉下来正好是垫脚石；站在块下面起跳会被砸 |
| E | 走廊里有 4 格宽的尖刺坑，矮天花板跳不过去。从支柱**左侧**蹬墙跳震断脆岩，吊块正好填满坑；在块下面炸它会被砸，炸到块本身则填不平 |
| F | 终点 |

## 结构

```
climb-proto/
├── index.html
└── src/
    ├── config.js          # 手感与规则参数
    ├── world.js           # 房间 ASCII + 布局，第一行是房间最顶上
    ├── Terrain.js         # 格子地形：爆炸、脆岩连锁、支撑检测、碎块下落、房间重置
    ├── main.js
    └── scenes/
        ├── BootScene.js   # 代码生成贴图
        └── GameScene.js   # 房间切换、玩家、蹬墙跳、怪物、尖刺、预览、特效、HUD
```

## 改关卡

房间之间的出入口要在相邻房间的同一行/列上开洞。每块泥土和脆岩都要连到岩石。
爆炸大小改 `config.js` 的 `explosionRadius`：1.5 是 3×3，2.0 是 3×3 加上下左右各一格。
