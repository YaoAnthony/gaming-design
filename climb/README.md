# Climb

「起跳即爆炸」的房间制解谜平台游戏。Vite + React + TypeScript + Phaser 3 + Redux Toolkit + Ant Design（弹窗等界面组件）+ Motion（界面动画）。

## 线上版本

推到 `main` 后 GitHub Actions 自动打包部署到 GitHub Pages（`.github/workflows/pages.yml`）。线上只有游戏（正中一个「开始游戏」），没有编辑器；地图在本地编辑器里改，「写入 world.json」后 push。

## 命令

```bash
npm install        # 安装依赖
npm run dev        # 开发服务器 http://localhost:5174
npm run build      # 类型检查 + 打包到 dist/
npm test           # vitest 单元测试
npm run gen-art    # 重新生成占位 PNG 美术到 src/asset/
```

## 多语言

`i18next` + `react-i18next`，入口 `src/i18n/index.ts`，文案在 `src/i18n/zh.json` / `en.json`。默认中文，浏览器是英文用英文，`localStorage['climb:lang']` 可以强制；`setLang('en')` 切换。目前只有玩家界面的文字走了 `t()`（开始、加载条、当前位置、死亡、通关）；编辑器是开发工具，保持中文。台词表（各机制文件夹里的 `dialogues.ts`）和层的「位置」文字暂时是中文字面量，要做多语言时改成 key 再查表。

## 数据流

- **房间布局**：`layout` 是稀疏网格，`null` 是空位（游戏里是实心岩石）。编辑器里房间以缩略图显示，可拖拽交换 / 移动，任意空位点「+」新建，选中的房间可删除。
- **地图**：`map/world.json` 是默认地图（多层项目 `{ floors: [{ id, name, model }] }`，旧的单层格式也能读）；运行时在 Redux `editor.project` 里，编辑器改的就是它，游戏也用它。自动存进 localStorage。开发服务器下编辑器有「写入 src/map/world.json」按钮（Vite 插件 `climb-save-map` 提供的 `POST /__climb/save-map`），一键写回源码；打包版本用「导出 world.json」手动覆盖。
- **存档**：游戏每进一个房间就把整张地图的当前格子状态、入口、统计写进 Redux `save`，并持久化。游戏页「继续」从存档恢复。
- **参数**：`game/config.ts` 是默认值，运行时在 Redux `config` 里，将来可以做调参面板。
- **Phaser → React**：直接 dispatch 到 `hud` / `save`。**React → Phaser**：`game/bridge.ts` 的事件总线，或场景启动时传数据。

## 机制（`game/mechanics/`）

玩法都是注册表里的**机制**，`GameScene` 只按生命周期调用它们，不认识具体玩法。每个机制一个文件夹，`index.ts` 里 `defineMechanic`，它的物件用 `机制.entity({...})` 注册在同一个文件夹里（`spawn` 直接拿到这个机制的实例）。

- **层机制**（`scope: 'floor'`）：决定这一层怎么玩，每层一个，接管玩家移动和按键、手机端按键布局。现在有 `platform`（平台跳 + 起跳爆炸，默认）和 `pacman`（吃豆人）。层设置里的「玩法」下拉就是这个列表；`floor.mode` 存机制 id，旧地图的 `'topdown'` 自动认成吃豆人。没选过的层，放了哪个层机制的物件就是哪个。
- **通用机制**（`scope: 'global'`）：哪层都能用，地图里放了它的物件就自动启用（`activeOn` 可以改规则）。`boss`、`goal`（终点）、`portal`（小城堡）、`textBlock`（文字方块）、`npc`（会说话的角色）、`carry`（携带，每层都开）、`slider`（设置滑块）、`locks`（钥匙与门）。

机制能用的东西都在 `core/PlayContext.ts`（地形、玩家、怪物、对话、房间查询、死亡 / 换层 / 存档、`mech('carry')` 拿别的机制）。可选的钩子在 `mechanics/define.ts` 的 `Mechanic`：`start`、`update`（每帧）、`updateAlive`（活着才跑）、`blocks`（额外挡路的格子）、`onRoomChanged`、`onClear` / `onReset`（重置；Boss 用返回值改复活点）、`onFuseBurn`、`persist`（存档 / 带到下一层）、`vortexTargets`、`bake`（建地形前改模型，比如把门烘成砖）。机制还能声明 `roomFlags`，编辑器房间面板自动出现对应开关（吃豆人的「左右打通」）。

**加一个新机制**：`mechanics/<名字>/index.ts` 里 `defineMechanic({ id, name, scope, create: ctx => new X(ctx) })` + 需要的 `.entity(...)`，然后在 `mechanics/index.ts` 加一行 import（顺序 = 每帧调用顺序 = 物品栏顺序）。单元测试里 `phaser` 被换成替身（`src/test/phaser-stub.ts`），所以注册表可以直接在 Node 里测。

## 塔：多层

第一层是塔外，走进「小城堡」物件（`T`，城门在贴图底部正中）进下一层，正式开始。进门有一段旋涡：镜头转着拉近城门，人、怪、骷髅和一把碎屑沿螺旋线缩进门里，然后淡出换层。编辑器画布上方是层标签，「添加一层」可以给每层单独的房间尺寸（比如标题层做成 40×20）。层顺序 = 标签顺序；「改名」弹窗里还有一栏「位置」，填了就在游戏左上角显示「当前位置: …」（深色底白字，不受画面影响；每层各自一句，比如塔外是「地下城」，进塔后是「???的家 - 第一层」）；「删除本层」删掉当前层。

**文字方块**（物品栏「文字」）：左键在画布上放一串字，字母由 3×5 像素字体拼成可炸的砖（默认「字块」`=`，可换成任何可炸砖）。侧栏改内容 / 砖种 / 目标层。游戏里这串字的砖全被炸掉，就淡出跳到目标层——标题层的 START / SETTING / QUIT 就是这样做的按钮。字体在 `game/world/font.ts`，支持 A–Z、0–9、`- ! ? .`、空格、换行。

## 假通关与真入口

到达「终点」建筑（`G`）只是**假通关**：彩纸 + 「通关！」，跳一下或点一下就继续玩，终点不再触发。真正的路在后面：骷髅挡着的小城堡是通往下一层（地下城）的入口。最后一层没有下一层时，城门才是真结束。

## 吃豆人层（俯视）

层设置的「玩法」选「吃豆人」（放了吃豆人物件的层不选也自动是），这一层没有重力，沿格子中线四方向走（想转的方向记住，到路口就转；前面是墙停在格子中央），没有跳跃和起跳爆炸。W / ↑ 是往上走；动作键只有空格（手机端一个淡白色圆键）。物品栏「吃豆人」分区：豆子（10 分）、大力丸（50 分）、鬼巢、葡萄点、隧道格；房间开关「左右打通（隧道）」让人从左边出去右边进来。右上角显示分数。死亡沿用 U DEAD，回本房间重置点；剧情开始前死亡，豆子全部复原（分数保留）。清空的判定只看小豆子，四个角的大力丸不算。

**鬼**（`game/mechanics/pacman/Ghosts.ts`）：放一个「鬼巢」在门口那一格，门下面留三格空气当巢。四只鬼：红的在门口直接出发，粉、青、橙分别 2 / 5 / 8 秒后出巢。目标各不同：红直追；粉堵你前方四格；青拿红鬼和你前方两格连线的两倍点夹击；橙离你超过 8 格才追、近了回自己角落。全体按"散开 7 秒、追 20 秒、散开 7、追 20、散开 5、追 20、散开 5、永久追"切换，切换瞬间掉头。大力丸：全体变蓝掉头减速可吃（6 秒起，每吃一颗大力丸短 0.8 秒，最短 1.5 秒；最后 1.5 秒闪白），吃鬼 200 / 400 / 800 / 1600 连击，被吃的变成眼睛飘回巢，1 秒后正常出来。鬼巢的门和巢内对人、对巡逻中的鬼都是墙。隧道格里鬼减速。人被鬼碰到 → 死亡。死亡 / R 重置：鬼回巢重新按节拍出，豆子复原（清空之后的追击阶段不复原）。**葡萄**：吃到第 70、170 颗豆子时在某个葡萄点出现 9 秒，吃到 300 分。

**画面**：鬼身体白底按只染色（`ghost.png` / `ghost2.png` 两帧裙边交替），眼珠跟着前进方向偏，蓝色惊吓态换锯齿脸并在最后闪白，眼睛态只剩眼睛，被炸死留一团散开的影子。手机端俯视层是 ▲▼◀▶ 十字键 + 一个无字的淡白圆键（炸弹）。

**清空之后**（`game/mechanics/pacman/PacScript.ts`，按时间戳推进，死亡重置不打断）：豆子吃光不结束，鬼提速 1.5 倍、永久追击（散开节拍作废，蓝色立刻结束）。6 秒后自动翻页的画外音（`pacman/dialogues.ts` 的 `taunt`，每句 `autoMs`），再 1 秒解锁**炸弹**（`pacman/Bombs.ts`）：只有空格（手机端动作键）能放，同时一颗，实体，人走开之后挡路（鬼也绕着走），1.5 秒后炸十字（四个方向各 2 格，岩石挡住，可炸砖炸掉并挡住后面）。炸到鬼鬼就死且不复活（500 分），炸到自己也死；死后回到的还是追击阶段（鬼仍然快、炸弹仍然有），不是重头来。鬼全灭 2 秒后骷髅王的对话（`king`），说完淡入出现在你面前两格，后续剧情待写。

## 携带（共用机制）

手上只有一个位置。蜡烛、钥匙都是"拿在手上"的东西：碰到就捡，手里已经有东西时两者交换，旧的留在原地（人走开之后才能再捡）。钥匙开门后用掉，手就空了。换层只带道具（蜡烛），钥匙留在本层。

## 钥匙与门

物品栏「钥匙与门」里点「添加一组」，每组一个颜色（蓝、绿、黄、红、紫、橙、粉、白、青，最多 9 组），同时出现同色的「钥匙」和「门」两支画笔。门只占空气格，右键擦；钥匙放地上。游戏里碰到钥匙就拿在手上（占用唯一的携带位，见上一节），拿着钥匙贴到同色的门上，这一组的门全部消失，钥匙用掉。开过的门死亡重置也不会关回来；拿走的钥匙不再出现。数据在 `model.locks`（`groups` / `doors` / `keys`），门在游戏里烘成 `%` 砖再按组染色。

## 设置房间的机关

「音量滑块」物件（`V`）：放在地上，喇叭图标右边伸出一条 8 格长的轨道，上面一个滑钮。走过去把它推到哪儿，音乐就多大（`config.musicVolume`，即时生效、记在本地）；喇叭旁边的声波弧线跟着变，推到最左是静音的红叉。滑块绑定的是 `GameConfig` 里的数字字段，以后要加别的设置就是再放一个绑不同字段的物件。

## 会说话的角色

「骷髅」物件（`N`）是挡在路上的小角色。走到它跟前一格半内强制进入对话（左右移动锁住，只能跳），每跳一次（也就是每炸一次）说下一句；最后一句说完再跳，它带着笑声（`bossLaugh`）淡出消失，路就通了。消失是这一层内永久的，死亡重置不会把它带回来。台词在 `game/mechanics/npc/dialogues.ts`，新角色 = 一段台词 + 一个 `npc.entity`（`spawn: (n, at) => n.addNpc(…)`）。放它的时候脚下用岩石，不然玩家跳的那几下会把它脚下炸空。

## Boss 房间

物品栏里的「Boss 大史莱姆」物件（`K`）放进哪个房间，那个房间就是 Boss 战。玩家进来先没事；往里走到离门口一格半以上，两侧入口封上岩石，复活点就定在这个位置，随后顶部出 5 格血条、大史莱姆从你放物件的位置落下。它的循环是：游走两三跳（离玩家太近往外跳、太远才靠近）→ 蓄力 0.7 秒（压扁变暗）→ 扑向玩家当时的位置、落地重震 → 喘气 1.6 秒并吐 2 只小史莱姆（上限 6）。喘气那段是砸它的窗口。碰到即死。**只有落石和引线能伤它**：快速下落的碎块砸中扣最多 4 格并被它吞掉，引线烧过的格子碰到它扣 2 格；受击后 0.8 秒无敌（闪烁），所以一次落石、一次引线各只算一下；起跳爆炸不伤它。血条清空后开门，同时 Boss 爆开射出一圈**穿墙火花**（`bossBurstCount / Speed / Ttl`）：不伤任何人，碰到引线端点就点燃。把引线埋在 Boss 房地板下、连到别处的门，打赢 Boss 就自动开路。打赢之前死掉或按 R，都回到关门的位置重来，门重新关、Boss 重新出场。打赢之后：在第一层、死在别的房间 → 直接回到 Boss 房，Boss 在你眼前再炸一次（引线重新点燃、路重新开）；死在 Boss 房里、或不在第一层 → Boss 回来，重新打。参数在 `config.bossHp / bossHopMs / bossSpitMs / bossMaxMinions`。

房间 O 是现成的 Boss 战：天花板挂着左右两块脆岩板和正中一块用脆岩吊着的泥土砧，地面三个引线端点各自沿墙爬上去，烧到天花板附近时把对应那块震下来。

## 地图迷雾

`game/fog/Fog.ts`。三种状态：没见过（全黑，地形 / 怪物 / 引线端点 / 爆炸预览都看不到）、见过但不在视野（半透明，能看地形看不到怪）、视野里（清晰）。

- **光照扩散**：以玩家为圆心的圆，亮度按直线距离衰减；光沿空气传播，实心格被照亮但挡住后面。没有光源时只看得见身边（`config.fogRadius`，1.5 格）；地上放一支「蜡烛」物件（`C`），它在地上自己就亮着（迷雾里远远能看见那一圈光），碰到就捡起来拿在右手，照明半径变成 8 格（道具的 `light`，在 `Items` 注册表里）。捡到的道具换层、死亡都不掉，随存档保存。炸开一堵墙，光会立刻透进去。
- **迷雾区**：编辑器里可以画 1-4 号区（叠在砖块上，不影响地形），没揭开前无论多亮都全黑；玩家踏进区内任一格整区永久揭开。用来藏秘密通道。
- **按房间开启**：房间面板里勾「这个房间启用迷雾」（`roomFlags[房间].fog: true`）。默认不启用；没开的房间全亮。旧的全局开关和 `noFog` 已去掉，载入时自动清理。
- 探索记忆随存档保存，不随死亡 / R 重置消失。渲染是一张房间大小的 RenderTexture，只在玩家换格子或地形变化时重画。

## 规则与砖块

基础砖块在 `game/registry/tiles.ts` 注册（属于某个机制的砖块，比如门 `%`，在那个机制的文件夹里注册），用特征组合声明：

```ts
defineTile({ id: 'B', name: '脆岩', color: 0xc9b27c, frame: TILE_FRAMES.brittle },
  Traits.Solid, Traits.Destructible(1), Traits.Chain);
```

| 能力 | 含义 |
| --- | --- |
| `Solid` | 实心，挡住玩家、怪物、碎块 |
| `Anchor` | 锚点：自己永不掉落，相连的实心格子都被它撑住 |
| `Destructible(n)` | 可被爆炸摧毁；`n` 是额外感应半径（格） |
| `Chain` | 被波及后沿同类格子连锁崩塌 |
| `Loose(n)` | 周围有爆炸就整块松脱掉落（范围外再加 n 格感应），相连同类一起掉 |
| `Hazard('提示')` | 碰到即死 |
| `Delay(ms)` | 连锁传导时每跳延迟 ms 毫秒才摧毁，能看到火苗跑过去 |
| `EndsOnly` | 只有链条两端能被爆炸点燃，中间段免疫 |
| `Hidden` | 不在编辑器物品栏显示 |

### 角色技能

起跳时发生什么也是注册表（`game/registry/skills.ts`）。技能拿到一个 `SkillContext`（查地形、摧毁格子、放特效），自己决定炸哪里、预览画什么：

```ts
defineSkill({
  id: 'drill', name: '定向钻孔',
  onJump(ctx) { const removed = ctx.destroy(ctx.previewCells(cells)); ctx.fx(ctx.jump.cell, removed, 1); },
  preview(ctx, jump) { return { outline: cells, removed: ctx.previewCells(cells) }; },
});
```

当前有 `blast`（默认，起跳点圆形爆炸）和 `drill`（示例，1 格宽 3 格深的定向钻孔）。用哪个由 `config.skill` 决定，游戏页有下拉可以切换。

### 引线（`game/fuse/Fuse.ts`）

引线**不是砖块**，是叠在地形之上的一层（`model.fuse[房间]`，`'W'` = 有引线），不占格子、不挡人，可以穿过空气和任何砖块。只有两端（同类邻居 ≤ 1）能被爆炸点燃（`config.fuseIgniteRadius`），点燃后从那头沿引线一格格烧过去（`config.fuseDelayMs`），烧到哪格就把那格的地形炸掉，**岩石也炸**（引线是唯一能开岩石的手段；岩石和泥土都是锚点，炸掉后周围失去支撑的沙土 / 脆岩会跟着掉）；经过空气只是过一下。游戏里只画端点（黄色节点），中间段完全不可见；编辑器里整条线自动拼贴显示。烧掉的引线随存档保存，R 重置房间会恢复。引线可以**跨房间**：两个房间交界处相邻的引线格会拼成一条，火照样烧过去；编辑器里边缘格会显示成连向隔壁，缩略图上也画出引线方便对齐。注意 R 只恢复当前房间那一段，已经烧到隔壁的部分不会回来。

引线在编辑器里的贴图是**自动拼贴**：按上/右/下/左有没有引线取 16 帧之一（`frame + 掩码`，上=1 右=2 下=4 左=8）。砖块系统也支持同样的机制：任何砖块加上 `autotile: true` 并在图集里放 16 帧即可；`gameFrame` 可以让砖块在游戏里和编辑器里长得不一样。

新砖块要有图集帧：在 `scripts/gen-art.mjs` 里画一帧（或换成手绘 PNG），在 `asset/index.ts` 的 `TILE_FRAMES` 加序号，然后注册。
