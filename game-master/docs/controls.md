# 键位

键盘、手柄、触屏三套输入做同一件事。手柄用浏览器 Gamepad API 的标准布局（Xbox、PS 按钮位置一样），按钮编号和动作的对应在 `src/shared/gamepad.ts` 的 `GAMEPAD_BUTTONS`，改键改这张表。认出手柄后，画面上的提示自动换成手柄图标（`store.input.device`）。

## 游戏里

| 键盘 | 手柄 | 动作 |
| --- | --- | --- |
| ← → / A D | 左摇杆 / 十字键 | 移动 |
| ↓ / S | 左摇杆 / 十字键往下 | 摘帽子、放下钥匙 |
| 按住 Shift / E | 按住 X（PS：□） | 抓箱子：贴着箱子按住，往反方向走就拉（触屏还没有这个键） |
| 空格 / ↑ / W | A（PS：✕） | 起跳（起跳点爆炸）、翻对话；吃豆人层放炸弹 |
| R | Y（PS：△） | 重置房间；死了之后复活 |
| ESC | Start | 暂停菜单（继续、设置、回到标题） |
| ESC | Back / Select | 编辑器试玩时回编辑器（试玩里 ESC 不开暂停菜单） |

节奏关卡每种玩法的按键在 `src/rhythm/modes.ts` 的 `hints`，画面底下会显示。

## 菜单（标题、设置、结局画面、通关弹窗）

| 键盘 | 手柄 | 鼠标 / 触屏 | 动作 |
| --- | --- | --- | --- |
| ↑ ↓ / W S | 十字键 / 左摇杆上下 | 移上去 | 换选项（按住连发） |
| ← → / A D | 十字键 / 左摇杆左右 | — | 调音量、换语言 |
| 回车 / 空格 | A（PS：✕）/ Start | 点一下 | 选中 |
| Esc / Backspace | B（PS：○）/ Back | — | 返回、关掉 |

- 实现在 `src/ui/menu/useMenuNav.ts`：键盘听 `keydown`，手柄每帧直接查 `navigator.getGamepads()`；连发的节奏（按住 380 毫秒后每 110 毫秒走一格）是纯函数 `menuRepeat`，有测试。
- 刚打开一个菜单时正按着的键要先松开才算，免得上一层按下的那一下连着把下一层也选了。
- B 在游戏里没有用处，只在菜单里当「返回」；游戏里的按钮表（`padAction`）不认它。
- 抓箱子是「按住」的键，不走按钮事件：`GameInput.read` 每帧读键盘 Shift / E 和手柄 `GAMEPAD_BUTTONS.grab`（X / □），放在 `MoveInput.grab` 里。
- 浏览器要等页面打开后按一下手柄上的键才认得出手柄；网页版第一屏「按任意键」时按手柄也行。
