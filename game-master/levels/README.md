# 文字关卡（levels/*.txt）

用文本画一整层，比在编辑器里一格格点更快，也方便改、方便看 diff。工具：

- `npm run level -- levels/floor2.txt`：检查。打印整层拼起来的字符画、物件统计、提醒和错误。
- `npm run level -- levels/floor2.txt --write`：写进 `src/map/world.json`。同 id 的层整层替换，没有就加在最后，别的层不动。写完在编辑器里点「载入」就能看到。
- 开发时不用先写进 world.json 就能试玩：浏览器控制台里 `await __climb.bot.load({ level: 'levels/floor2.txt' })`，见 `src/dev/bot.ts`。

解析和编译在 `scripts/levelFormat.mjs`（纯函数，Node 和浏览器都能用），命令行在 `scripts/level.mjs`。

## 格式

以 `#` 开头的是注释。指令：

```
floor claude2          层 id（唯一）
name Floor 2           层名（游戏里换层时闪一下；中文靠 i18n 的 map.* 翻译）
place Key Well         左上角的地点名（可选）
music none             背景音乐（可选）
background cave        这一层的背景（可选）：sky（默认星空）/ cave / dusk，清单在 src/asset/backgrounds.ts
roombg B dusk          房间 B 单独换背景（可选）
size 24 16             房间宽、高（格）
group 1 #4cc9f0        钥匙与门的一组：组号和颜色
flag B fog             房间开关：fog = 全屋暗
layout                 房间布局，一个字符一个房间，. = 空位（实心岩石）
AB
CD

room A                 房间 A 的主图：size 指定的行数，每行 size 指定的宽度
RRRRRRRR...
...

room A fuse            房间 A 的引线层（可选）：. 无，W 橙，2 蓝，4 绿，8 紫，混合用十六进制相加
room A movers          房间 A 的移动方块层（可选）：h 左右，v 上下，只能画在 R r = _ E 上
room A fog             房间 A 的迷雾区（可选）：1-4 区号
```

主图里一个字符一格：

| 字符 | 是什么 |
| --- | --- |
| `.` | 空气 |
| `R` `r` `B` `S` `X` `Z` `=` `_` `E` | 岩石、碎岩、脆岩、沙土、尖刺、纸、字块、木板、王之炸药（史莱姆王死了就炸开 3x3） |
| `P` `M` `G` `T` `C` `h` `b` `D` `q` `Q` `N` `K` `k` `V` | 出生点、怪物、终点、城堡、蜡烛、帽子、小箱子、大箱子、压板 1x1、压板 1x2、骷髅、Boss 史莱姆王、Boss 触发点、音量滑块（底下是空气） |
| `Y` `W` `L` `U` `J` `g` | 主线剧情：剧情墙（游戏里是岩石，剧情走到了才塌开）、施工牌、线框格、素材堆、菜单按钮、Game Master 的化身（底下是空气） |
| `1`-`9` | 这一组的钥匙（底下是空气） |
| `!` `@` `$` `^` | 第 1、2、3、4 组的门（底下是空气） |

检查会提醒：房间交界一边空一边堵、整层外沿有空气（会走出地图）。会报错：行数 / 宽度不对、不认识的字符、出生点不是正好一个、钥匙 / 门没有对应的 group、移动方块画在不能搬的砖上。

## 设计时量出来的数（主角 1 格高时）

- 起跳：最高约 3 格（96~100 像素），刚好跳上 3 格高的台子。悬空的薄平台从斜下方跳会撞到底面，最好别超过 2 格。
- 助跑跳：能跳过 4~5 格宽的坑，大约飞 6 格远。
- 任何岩石墙都能靠单墙蹬墙跳一路爬上去，只有天花板能拦住。碎岩墙爬的时候会被炸掉。
- 起跳的爆炸以脚下那一格为中心，炸 3×3（斜角也算，距离 ≤ 1.5 格）。站在岩石上跳，也能炸到斜下方那一格。
- 1 格宽的洞，走过去会直接跨过去，要停在正上方才掉得下去；想让人掉下去就开 2 格。
- 悬空的沙土、脆岩不稳：只要哪里的地形一变（比如别处炸了一下），没连到岩石的就会掉下来。想让它挂着，就接在岩石上。
- 脆岩被震松会整块掉，砸到尖刺上会盖住尖刺，人可以落在上面；砸到钥匙上，钥匙会被顶到石头上面。
- 箱子会从木板上漏下去（人不会），落在压板上就点燃压板旁边的引线。
- 移动方块能驮着钥匙、箱子、人一起走。
- 驮着的钥匙撞上钥匙那一行的墙或横梁，会被推回墙外、留在原地，方块从底下走开，钥匙就在墙跟前掉下去（「刮板」）。横梁用碎岩（`r`）挂在天花板下面一格，跳起来能炸掉；炸掉哪几根，决定钥匙在哪掉。见第四层。
- 方块一开始被一块沙土卡着（沙土接在岩石上才挂得住），站在方块上跳，爆炸外一圈把沙土震碎就放行。
- 一张纸落在哪就变成什么（见第五层）：落到怪物头上 = 船（怪物驮着走，人和钥匙都能站上去，尖刺伤不到怪物）；落进 1 格深的缺口 = 桥（和地面齐平，怪物当地面走过去；1 格深的缺口对怪物就是悬崖）；怪物站在纸上时把纸震松 = 电梯（纸载着怪物每秒 55 像素往下降）。
- 电梯的落点要挖一格深、和纸一样宽的凹槽：直接落在地面上会多出一级 1 格高的台阶，怪物在台阶上走到边就掉头，被困在纸岛上。
- 起跳把纸震松的范围是 2.5 格（爆炸 1.5 + 纸 1），隔着岩石也算；引线烧过的格子周围 1 格的纸也会松。
- 骑着起跳，爆炸中心在纸上那一格，能炸掉身边的碎岩。
- 骑纸过房间边界不记复活点（入口在尖刺河上），死了回到上一个走着进来的入口。
- 引线的火每格 90 毫秒，一秒约 11 格；人跑一秒约 7 格。要人和火赛跑，就让火先绕一段远路（见第六层 B：紫火先钻进天花板往前冲，再从桥的另一头往回吃）。
- 引线经过的岩石变成碎岩，人一跳就能炸掉：引线竖着穿过人走的地板会变成一口一跳一层的「挖坑」陷阱。竖线要放在人碰不到的地方（第六层 D 从城堡里面往外烧）。
- 引线头可以放在地板正下方的空气里：人站在地板上起跳（爆炸中心就是脚下那格地板）就能点着，引线不用穿过地板。
- 怪物推得动小箱子，朝它走的方向推，推到墙或压板上停下。箱子要落在怪物「身后」，它才会往前推（第六层 C）。
- 引线烧过的格子周围 1 格的脆岩会松脱掉下来：一根引线可以顺路震下一块石板当桥（第六层 A）。
- 尖刺默认挂在下面那格上；下面是空的就挂到旁边的墙上（左 / 右 / 两边都有墙就两边都挂，两边挂的刺小一半），游戏和编辑器里都会自动换朝向。脚下被炸掉、旁边还有墙的尖刺不会碎，会改挂到墙上；三边都空才碎。
- 玩家有 3 颗心：碰到尖刺、怪物、Boss 扣一颗、被弹开、无敌 1.5 秒（被压、被埋还是直接死）。设计尖刺坑时别指望「碰一下就死」：掉进窄坑会被弹起来再落回去，连扣几次才死。
