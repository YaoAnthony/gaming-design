# ===== 第四层「传送带」 =====
# 新东西：钥匙坐在移动方块（传送带）上被带着走；路上挂着的碎岩横梁挡在钥匙那一行，钥匙撞上就被「刮」下来，
# 传送带从底下走开，钥匙在横梁跟前掉下去。炸掉哪几根横梁，决定钥匙在哪掉。每条传送带开始时被一块沙土卡着，
# 站在上面起跳把沙土震碎才放行（沙土在爆炸外一圈也会碎）。
#   A「刮板」：路上两根横梁，左边那根底下是尖刺，右边那根底下是活板门。先站在左边横梁正上方跳，把它炸掉；
#     再站到沙土上方跳，放行传送带：钥匙被右边的横梁刮下来，砸开活板门，从走道尽头跳下去、钻进活板门到 B。
#     顺序反了，钥匙会被左边的横梁刮进尖刺，按 R 重来。
#   B + C「两把钥匙」（两屋联动）：一条传送带从 B 跑进 C，上面坐着红、蓝两把钥匙（蓝的在前）。
#     B 有一根横梁、C 有两根：哪根底下是尖刺、哪根底下是竖井，要两个房间都看过才知道。
#     竖井里依次是蓝色活板门、红色活板门，最底下是城堡。
#     炸掉 B 的横梁和 C 左边那根（底下都是尖刺），留着 C 右边那根，回 B 放行：
#     蓝钥匙先被刮下来砸开蓝门，红钥匙跟着被刮下来，从开了的洞掉下去砸开红门，跳进竖井就是城堡。
