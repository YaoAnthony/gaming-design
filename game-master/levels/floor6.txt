# ===== 第六层「引线工坊」 =====
# 一件事：火能到你去不了的地方。岩石人炸不动，火烧一次裂成碎岩（橙 / 蓝），紫色的火直接把岩石烧没。
#   A 起「火种」：出生点旁边就是一个引线头，前面一堵四格厚的岩墙。跳一下，火钻进墙里、再爬上天花板、一路烧到刺坑上方，
#     墙中间被烧出一条碎岩缝（一格高，正好是人的高度），一下下跳着炸过去；坑顶挂着的脆岩板也被火震下来，砸进坑里当桥。
#   B 承「紫火」：一座一格厚的岩石桥，对岸的门上方封着一把钥匙。紫色引线头在桥这头：紫火先钻进天花板往前跑，
#     冲下来从桥的另一头开始把桥吃掉，同时分一股去烧掉托着钥匙的石台，钥匙掉下来开门。点完火就跑，赶在火冲下来之前过桥。
#   C 转「机关房」：火够不着要开的东西，要借怪物的手。从走廊往下看是一间带刺的机关房：
#     石台上的箱子、笼子里的怪物、最右头一块压板，压板底下引出一根蓝线。走廊地板底下挂着两个引线头：
#     紫的烧掉箱子下面的石台（箱子掉下来），橙的烧掉笼子（怪物出来）。怪物往哪走就把箱子往哪推：
#     要先放箱子、再放怪物，怪物从后面把箱子一路推上压板。顺序反了箱子可能被推到左头卡死（R 重来）。
#   D 合「回信」（和 C 联动）：压板点燃的蓝火沿着地底穿过房间边界来到 D，从城堡底下钻上来，由里往外把门口的岩墙烧成碎岩，炸开进城堡。
